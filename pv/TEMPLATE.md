# PV 动效模板：节拍网格驱动的矢量动态图形

本目录是一次"视觉语言研究"的产物。参考对象是一支约 1 分钟的游戏活动宣传 PV。
本作只提取并用代码复现参考片的**技法**，包括节奏、转场、微动效、配色逻辑、版式语法和音频结构。
以下内容都没有使用，也没有描摹：
- 角色、商标、Logo、原片文字
- 原片音乐旋律与音频素材
- 原片 3D 模型与画面

参考片的"信息层"也按同样的结构原创补齐了：
- 虚构游戏「DASTER · 相位档案」
- 虚构活动「相位跃迁 #01 · 共生回路」
- 新干员「藤曦 VINELIGHT」
- 时装「光环工坊 · 静默花期」

立绘、Logo、适龄标识都做成**可替换的占位槽**，默认显示原创的剪影占位图（见 §2.8）。

- 2D 图形与配乐：在浏览器里实时生成
- 3D 镜头：Blender Cycles 预渲染的背景底片（plate），见 §2.9

- 在线播放：`/pv/`（空格 播放/暂停，←/→ 按小节跳转，`d` 显示镜头名，`?t=秒` 从指定时间开始）
- 代码：
  - `engine.js`：节拍时钟、缓动、图元、迷你 3D
  - `config.js`：**全部文案与素材槽**
  - `assets.js`：占位图、Logo 槽、3D 底片加载
  - `fx.js`：WebGL 后期
  - `audio.js`：合成配乐
  - `scenes.js`：镜头与转场
  - `main.js`：合成与播放器
  - `blender/plates.py`：Cycles 底片
  - `blender/pack.py`：打包为 30 fps 帧序列与 webm

## 1. 参考片拆解结论（风格层面）

### 1.1 节奏：一切对齐小节
| 项 | 测量结果 |
|---|---|
| 速度 | 约 170 BPM（Drum & Bass / 半拍 85 BPM 的听感） |
| 1 小节 | 4 拍 ≈ 1.41 s |
| 剪辑点 | 16 个主要剪辑点里，绝大多数落在**小节第 1 拍 ±50 ms** 以内。少数落在半小节或最后一个八分音符（抢拍）上 |
| 单镜头时长 | 1–3 小节。高潮段常见 1 小节甚至半小节一切 |
| 能量曲线 | 前奏（约 8 小节，铺底 + 长音 + 下潜 sub）→ 推进（约 8 小节，半拍鼓 + 滑音贝斯 + 上扬噪声，结尾"断拍"静音）→ 主段（约 16–20 小节，满鼓 + 高频密集）→ 收尾（低通滤波，频谱重心从约 2900 Hz 降到约 1300 Hz）→ 片尾静音 |

测量方法：
- 剪辑点：ffmpeg `scene` 分数
- 节拍：谱通量起音检测 + 自相关求 BPM + 网格拟合
- 能量与重心：分段 RMS 和频谱重心

### 1.1b 画幅：宽银幕黑边是结构的一部分
逐帧测量上下黑边（每 0.25 s 一次）后得到：

| 时段 | 画幅 |
|---|---|
| 0–1.5 s | 黑场 Logo |
| 1.5–46.5 s | 上下各 8.3% 黑边，画面约 2.13:1 |
| 46.5–52 s（角色/时装页） | 满屏 16:9 |
| 52–57 s（三圆透镜） | 回到黑边 |
| 57–59 s（主视觉） | 满屏 |
| 59 s 起 | 黑场标识 |

**画幅的开合本身就是段落标记**："宣传信息页"用满屏，"氛围叙事"用宽银幕。

本作实现：
- `PV.lboxAt(bar)` 决定哪一段带黑边
- 黑边在后期着色器最后一步画出，不受缩放、抖动、旋涡等效果影响
- HUD 元素通过 `PV.LB` 自动避开黑边

### 1.1c 片尾信息结构（第一版缺失，现已补齐）
| 段 | 内容语法 | 本作 |
|---|---|---|
| 蜂巢墙 | 各角色/事件的六边形徽章，按八分音符逐个弹出，末尾做像素溶解 | `wall` + 3D 方块墙底片 |
| 角色登场 | 马赛克/RGB 切片故障，然后显出半身立绘。右侧黑色名牌，底部一条强调色长条，左下大号名字逐字"故障"出现 | `operator` |
| 时装页 | 方块马赛克转场 → 纸白版式、强调色圆环、描边衬线大字水印，全身立绘从圆内放大后落位。成型版式依次为：左上游戏标 → 年份系列 → 大标题 → 黑色信息条 + 强调色条 → 信息行 → 右上 "NEW / COMING SOON" → 左下品牌名 → 角标与右缘刻度 | `outfit` |
| 三圆透镜 | 黑底三圆取景，里面是玻璃世界。末尾毛玻璃后透出人物剪影，加一道扫光 | `lens` + 底片 |
| 主视觉 | 三圆上沿与地面组成的异形遮罩内放 3D 场景；上方正中活动徽章和标题，左上游戏标，右上合作方标 | `kv` + 底片 |
| 标识片尾 | 黑场上依次淡入淡出平台、开发商、适龄提示，约 8 s，几乎静音 | `slates` |

### 1.2 色彩系统
- **主色**：高饱和青（本作 `#2fd6c6`），用作"信号色"。可以大面积平涂整屏，也可以只做细线和小图标
- **底色**：偏暖的纸白 `#ecedeb`、中灰 `#9d9fa2`、近黑 `#1a1b1e`
- **过渡色**：前奏用柔和漏光色（青、鲑鱼粉、淡紫）做雾化氛围，进入主段后收敛为"青 + 白 + 灰"三色
- 规律：**一屏只有一个强调色**。暗场用灰蓝金属色，亮场用纸白加青
- **第二强调色只在角色/时装段出现**（参考片用粉色，本作改用珊瑚色 `CONFIG.accent2`），用来把"商品信息"和"世界观氛围"在视觉上区分开

### 1.3 转场清单（逐帧观察到的手法 → 本作实现）
| 手法 | 观察到的细节 | 本作实现 |
|---|---|---|
| 液态圆团擦除 | 多个圆从角落膨胀、合并后覆盖全屏，再从对角收缩露出下一镜。约半小节 | `TRANS: blob`，两组圆的 inC/outC 半径 |
| 漏光叠化 | 两镜交叠约 0.25–0.3 小节，中间有一次偏暖的白闪 | 场景 `xin` 叠化 + `flash` 三角包络 |
| 竖向拉丝（slit-scan） | 画面被切成细竖条，每条随机纵向拉伸，同时叠加 RGB 分离，用于退出暗场 | `fx.slit` + `fx.rgb`，按 1 小节 inQ 爬升 |
| 贯穿元素 | 一条细正弦线跨越多个镜头保持不动，形成视觉连续 | S0→S1→S5 共用 `PV.sine` |
| 白闪 / 青闪 | 1–2 帧满屏色块，落在强拍 | `flash12` `cyan24` `cyan36` |
| 反色帧 | 单帧反相，制造硬切冲击 | `inv18` `inv27` |
| 黑圆光圈 | 画面内元素（黑色圆盘）放大成全屏，再以挖孔方式打开下一镜 | `iris`（evenodd 挖孔） |
| 断拍黑屏 | 高潮前最后一个八分音符全黑，音频同时静音 | `band` 场景的 `lb >= 3.5` 分支 |
| 旋涡擦除 | 漩涡扭曲旧画面，青色旋臂填满后再反向解旋出新画面 | `fx.swirl` ± 符号翻转 + 螺旋臂覆盖 |
| 像素化溶解 | 块尺寸从 1 升到约 36，下一镜再反向降回 | `fx.pixel` |
| 三圆遮罩 | 三个相交圆作为取景窗，先被纯色填满，再收缩露出内部 | `lens` 场景的 clip + 青圆收缩 |
| 方向拖影 | 高速物体带同方向模糊，拖影强度随军鼓脉冲 | `fx.smear` 16 次采样方向模糊 |

### 1.4 微动效清单（容易漏看的部分）
- **八分音符逐件搭建**：板片、图标、柱状图每个八分音符出现一个，入场用 outE（快进慢停）或 outBack（轻微回弹）
- **踩点缩放**：底鼓时整体放大 2–5%，约 0.2 s 指数衰减（`PV.env('kick')`）
- **军鼓 RGB**：军鼓瞬间 RGB 分离 3–6 px，然后衰减
- **阶梯运动**：大字每拍"跳一格"。拍内 outE 走完，拍间静止，形成机械感
- **HUD 呼吸**：角标、刻度、小方框标签始终做缓慢漂移，保证静态画面也在动
- **景深**：大量圆点按深度决定硬度，焦平面内清晰、前后发虚，模拟浅景深
- **颗粒 + 暗角**：全片都有 3–7% 颗粒；暗场暗角更重（0.5），亮场几乎不加（0.1–0.15）

### 1.5 音频风格（仅风格参数，未采样、未扒谱）
- 170 BPM 两步式破拍：底鼓在 1 拍和 3 拍后半拍，军鼓在 2、4 拍，带弱音军鼓
- 前奏：宽铺底和声 + 纯正弦 sub + 高频空气噪声
- 推进段：sub 做弧形滑音（频谱上是一个"拱形"），加 4 小节上扬噪声，结尾断拍
- 主段：reese 贝斯（两路失谐锯齿波 + 失真 + 随节拍摆动的低通）+ 反拍和弦短音 + 每 4 小节加花
- 收尾：主总线低通从 18 kHz 扫到约 1.4 kHz，只留铺底和 sub
- 过渡音效：冲击低频（impact）、噪声扫频（whoosh / swell）、界面提示音（blip）与画面元素一一对应

## 2. 可迁移模板

### 2.1 小节结构模板（51 小节 ≈ 72 s @170 BPM）
```
小节      段落        画幅    镜头密度        画面主调                音频
0–1       Logo        满屏黑   1 镜            游戏标闪入              swell
1–8       前奏        宽银幕   2 小节/镜       漏光、玻璃雾、线稿→3D塔  铺底 + sub + 拨弦
8–16      推进        宽银幕   1–2 小节/镜     纸白 HUD + 暗场城市      半拍鼓 + 滑音 + 上扬噪声 → 断拍
16–36     主段        宽银幕   0.5–2 小节/镜   青/白/灰，活动名动态字   满鼓 + reese + 加花
36–38     徽章墙      宽银幕   1 镜            3D 方块墙 + 六边形徽章   低通扫频 + 上扬
38–39.5   干员登场    满屏     1 镜            立绘故障显现 + 名牌      两步鼓再起，亮拨弦
39.5–42   时装页      满屏     1 镜            纸白版式 + 珊瑚色         同上 → 断拍
42–45     三圆透镜    宽银幕   1 镜            玻璃世界 + 人物剪影       冲击 + 宽铺底 + 空气声
45–47     主视觉      满屏     1 镜            3D 场景 + 活动标题/日期   最终冲击 + 余响
47–51     标识片尾    黑场     3 块           平台 / 开发商 / 适龄      近乎静音，每块一声轻提示
```
换曲子时只需改 `PV.BPM`。所有镜头和转场都用"小节"计时，会自动适配新速度。

### 2.2 新增一个镜头
```js
scene('name', 起始小节, 结束小节, (g, s) => {
  // s.t 全局秒 · s.lt 镜头内秒 · s.u 0..1 · s.lb 镜头内拍数 · s.gb 全局拍数
  paper(g, s.t);                                   // 背景
  const k = E.outBack(seg(s.lb, 0, 0.5));          // 第 1 拍内弹出
  PV.mark(g, W / 2, H / 2, 40 * k, C.cyan);        // 元素
  return { zoom: 1 + 0.03 * PV.env('kick', s.t) }; // 后期参数（可选）
}, { xin: 0.25 });                                  // 与上一镜叠化 0.25 小节（可选）
```

### 2.3 新增一个转场
```js
tr('名字', 起始小节, 结束小节,
   k => ({ flash: [1, 1, 1, 1 - k], rgb: 8 * (1 - k) }),  // 后期包络（k: 0→1）
   (g, k) => { /* 可选：在两镜之上绘制遮罩 / 图形 */ });
```
后期参数合并规则：
- `zoom` 相乘
- `flash` 取不透明度最大的一个
- 其余取最大值

### 2.4 缓动选择规则
| 场景 | 缓动 |
|---|---|
| 元素入场 / 滑入 | `outE`（指数减速，最"利落"） |
| 图标弹出 | `outBack` |
| 离场 / 被吸走 | `inC` / `inQ` |
| 镜头推拉、编排位移 | `ioC` |
| 转场前半段累积 | `inC` 或 `inQ`；后半段释放用 `outC` |
| 节拍脉冲 | `exp(-3·Δt/decay)`，decay 取 0.18–0.25 s |

### 2.5 音画同步原则
1. **唯一时钟**：播放时，画面时间取 `AudioContext.currentTime`，不用 `performance.now()`
2. **同一份乐谱驱动两边**：`audio.js` 生成事件表，同时写入 `PV.hits`。画面只读 `PV.env(name, t)`，不在画面里手写节拍时间
3. **剪辑落在第 1 拍**。高潮前一个八分音符断拍，画面同时黑屏
4. **过渡音效与转场同长**：whoosh 等于 swirl 时长，swell 等于漏光时长

### 2.6 替换清单（做自己的版本时）
- [ ] `config.js`：游戏名、活动名与编号、日期、干员与时装文案、第二强调色
- [ ] `config.js` 里的素材槽：`operator.bust`、`outfit.art`、`game.logo`、`event.emblem`、`studio.logo`、`slates[].logo`
- [ ] `PV.C`：主色、纸白、墨色
- [ ] `PV.mark`：你的标志（本作是原创的"六边形 + D 形箭头"）
- [ ] `audio.js` 的 `CH` 和弦表、`ROOT` 根音、BPM
- [ ] `blender/plates.py`：各 3D 镜头的几何与灯光，改完后重新渲染并打包
- [ ] 镜头表：保持"段落密度 + 画幅开合"结构，替换各镜内容

### 2.7 验证方法（本仓库实际使用过）
- 截帧：`?still=1&t=秒`，再调用 `PV.renderAt(t)` 渲染任意帧，用 Playwright 截图拼成联系表检查
- 音频：`PV.renderOffline()` 离线渲染成 WAV，与参考片比较 BPM、分段 RMS 和频谱重心，并检查削波

### 2.8 素材槽（立绘 / Logo / 适龄标识）
`config.js` 里每个 `art` / `logo` 字段可以填一个图片 URL（推荐用透明 PNG）。

- **填 `null`**：画原创占位，保证成片完整
  - 立绘：灰色剪影人物，加虚线框和 "ART SLOT · 立绘占位" 标签
  - Logo：虚线框加名称
  - 适龄标识：示意徽章
- **不改文件临时替换**：`?bust=半身图URL&full=全身图URL&logo=游戏标URL`
- **尺寸建议**：
  - 半身立绘约 1:1
  - 全身立绘约 1:2，人物朝左侧留白

占位剪影是刻意做得很"通用"的原创形象，不对应任何现有角色。

### 2.9 3D 底片流程（Blender Cycles）
Canvas 负责 HUD、文字、转场和后期；真实质感部分预渲染成底片：
- 玻璃折射
- 金属各向异性高光
- 景深虚化
- 运动模糊

```
cd pv/blender
sh render_all.sh tunnel:1:16 glass:2 tower:2 cubefield:2 wall:2 lens:2 kv:2   # 镜头:隔帧:采样
FFMPEG=ffmpeg python3 pack.py tunnel glass tower cubefield wall lens kv
```

- **时间对齐**：第 f 帧对应镜头内时间 `lt = f/30`，与场景代码拿到的 `s.lt` 完全一致，所以 2D 叠层能跟住 3D 机位
- **渲染时间**：4 核 CPU 上约 8–40 s/帧。实际使用的设置：
  - 12–16 spp，打开 OIDN 降噪
  - 75% 分辨率
  - 深度雾用 mist 通道在合成器里完成（体积雾要慢约 5 倍），并用深度遮罩保留天空渐变
  - 慢镜头隔帧渲染，由 `pack.py` 做运动补偿插帧补回 30 fps
- **播放**：网页播放用 `plates/<shot>.webm`（跟随音频时钟 seek）；逐帧导出用 `?plates=frames` 读 JPEG 序列，结果完全确定
- **没有底片时**：场景自动回退到 Canvas 程序化绘制

## 3. 与参考片的已知差距
- 3D 底片是 CPU 上的低采样渲染，采样和分辨率都低于参考片的离线渲染；模型是基础几何体，没有做雕刻或贴图
- 立绘是占位剪影。参考片的角色段靠插画本身撑起来，换上真实立绘之后这一段的观感会有质变
- 旋涡、拉丝、拖影都是单遍着色器近似，没有逐帧运动矢量
- 配乐是原创的程序化合成，只复现速度、结构、编曲角色和频谱走向，不追求音色质感
